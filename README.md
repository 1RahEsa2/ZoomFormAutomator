# ZoomFormAutomator

An automated solution designed to streamline sending Zoom meeting links to participants who complete a registration form.

## Features
- Automatically captures form submissions.
- Sends personalized Zoom links via email or notification.
- Lightweight and easy to configure.

## Prerequisites
- Form API credentials (e.g., Google Forms, Typeform, etc.)
- Zoom API / Webhook credentials
